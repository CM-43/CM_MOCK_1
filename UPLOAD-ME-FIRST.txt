THE ONE MISTAKE TO AVOID
------------------------
GitHub's web uploader keeps your folders ONLY if you drag the FOLDERS
themselves. If you open a folder and drag the files out of it, every file
lands loose in the root and the Mock Test breaks.

So: drag the FIVE FOLDERS and the FIVE LOOSE FILES listed below. Do not
open any folder first.

STEP BY STEP
------------
1.  Go to github.com and create a NEW, EMPTY repository.
    Name it exactly:  CM_MOCK_1
    Make it Public. Do NOT tick "Add a README file".

2.  On the empty repository page, click the words
        "uploading an existing file"

3.  Open this CM_MOCK_1 folder in File Explorer.
    Press Ctrl+A to select everything.
    Drag it all onto the GitHub page in one go.

4.  Wait for the count to finish. It should say 131 files.
    If it says fewer than 120, something was missed - start again.

5.  Scroll down, click the green "Commit changes" button.

6.  Settings  ->  Pages  ->  Branch: main  ->  Folder: / (root)  ->  Save

7.  Wait two minutes.
